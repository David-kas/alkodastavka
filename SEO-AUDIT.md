## P0 — Критические (исправлено в коде)

### 1. HTTP 403 для десктоп-пользователей (`middleware.js`)

**Было:** не-мобильным пользователям без совпадения с шаблоном `bot` отдавался **403**.  
**Риск для Яндекса:** ухудшение поведенческих факторов, расхождение «мобильная/десктопная» версия, возможные проблемы с превью и ручными проверками (не все User-Agent попадают в список).  
**Исправление:** блок снят; middleware только **301 со старых зеркал** на `https://alkodastavka.vercel.app`.

### 2. Циклические редиректы (`vercel.json` + `middleware.js`)

**Было:** три правила `alkodastavka.vercel.app` → `alkodastavka.vercel.app`; в middleware `OLD_HOSTS` содержал **тот же** хост, что и `NEW_ORIGIN` → бесконечный 301.  
**Исправление:** саморедиректы удалены; 301 только с `alkodostavka24.online`, `www.alkodostavka24.online`, `dostavka-alkogolya-24.vercel.app`.

### 3. Sitemap без товарных URL и с фиктивным `lastmod`

**Было:** ~273 URL, **0** `/product/`, единая дата `2026-07-01`.  
**Исправление:** `scripts/rebuild-sitemap.mjs` — **450** URL, **138** товаров, `lastmod` = дата изменения файла (без verify/tmp).

### 4. Неподтверждённая микроразметка AggregateRating

**Было:** на главной, в каталоге, в генераторе `seo-full-audit.mjs`.  
**Исправление:** `scripts/remove-unverified-ratings.mjs`; шаблон каталога в audit-скрипте очищен.

### 5. Утечка Telegram-токена

**Было:** `api/config.local.php` с реальным `bot_token` в репозитории.  
**Исправление:** чтение из `getenv()`; файл добавлен в `.gitignore`. **Токен на стороне Telegram следует перевыпустить** (компрометация до правки).

**Решение:** 301 с устаревших корневых категорий на актуальные `/kategoria/*` (контент и разметка там полнее).
