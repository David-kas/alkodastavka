# SEO-PLAN — дальнейшее продвижение (Яндекс)

Основной домен: `https://alkodastavka.vercel.app` (при появлении брендового домена — единый 301 и смена canonical **одним релизом**).

## Фаза 1 — После деплоя (1–3 дня)

1. **Яндекс Вебмастер:** подтвердить зеркало, загрузить новый `sitemap.xml`, запросить переобход главной и `catalog.html`.
2. **Проверить ответы:** главная и каталог с десктопного UA — **200**, без 403 и петель 301 (curl / инструмент Вебмастера).
3. **Микроразметка:** валидатор Яндекса для главной и 2–3 товаров — без AggregateRating.
4. **Telegram:** перевыпустить bot token после удаления секрета из PHP-файла.
5. **Метрика:** цели «звонок / WhatsApp» без изменений; сравнить отказы ПК до/после снятия 403.

## Фаза 2 — Семантика и контент (2–4 недели)

| Запрос | Владелец страницы | Действие |
|--------|-------------------|----------|
| Доставка алкоголя | `/` | Удерживать Title под фактический контент; не размывать H1 на `city-*` |
| Доставка алкоголя Москва | `/` | Усилить блок «география» + ссылки на `rayony.html`, не копировать на каждый район |
| Доставка алкоголя круглосуточно | `/dostavka-nochyu-moskva.html` | Внутренние ссылки с главной 1–2 анкорами, не десятки |
| Заказать алкоголь | `/catalog.html` | Актуальность цен/наличия в JSON и HTML |
| Алкоголь с доставкой | `/` + категории | Категории — НЧ; главная — ВЧ |

**Районы/метро:** не переписывать массово; точечно добавлять уникальные детали (ориентиры, типовые сроки) на 5–10 приоритетных локаций из Вебмастера по показам.

## Фаза 3 — Техника и CWV (постоянно)

- Убедиться, что `/photo/*` отдаются с продакшена или CDN; иначе массовые placeholder ухудшают CTR в сниппете.
- `npm run build:assets && npm run patch:perf` перед релизами.
- Кэш статики уже в `vercel.json`; следить за размером `window.__PRODUCTS__` на карточках (дублирование JSON на каждой странице — техдолг perf).

## Фаза 4 — Коммерческие факторы (Яндекс)

- Единый телефон в шапке, футере, schema `Organization`.
- 18+, оплата, сроки — видимые на главной и `/delivery/`.
- При наличии — отзывы с реальными источниками; только тогда возвращать `AggregateRating` с `review` / ссылкой на площадку.

## KPI для контроля (только по Вебмастеру/Метрике)

- Доля страниц в поиске с ростом после обновления sitemap
- Входы по целевым запросам на `/` и `/catalog.html`
- Ошибки обхода: 0×403, 0×циклических 301
- Среднее время доставки LCP на мобильном (цель &lt; 2.5 s на главной)
